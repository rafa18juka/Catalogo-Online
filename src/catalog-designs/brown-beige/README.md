# Brown Beige Modern

Modelo criado a partir das quatro paginas de referencia exportadas do Canva.

Contrato do renderer:

- capa editorial com imagem grande, chamada dinamica e logomarca da empresa;
- sumario com links para a primeira pagina de cada colecao;
- abertura de colecao com hero visual e dois produtos em destaque;
- grade padrao com ate 8 produtos por pagina;
- clique no nome/badge da colecao para voltar ao sumario;
- SKU sobre a imagem do produto;
- campos do produto controlados pelos toggles do painel dev/empresa;
- amostras de cores quando `colors` existir e variacoes estiverem visiveis.

O SVG do Canva foi usado como referencia visual. O modelo final e React/CSS para que os dados do catalogo sejam sempre dinamicos.
